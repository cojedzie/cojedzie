# Section

A titled block of the page, like "Odjazdy" or "Komunikaty". The header shows the `icon` and `title`, the `#actions`
slot puts buttons on its right and the default slot is the content.

<Canvas of={UiSectionStories.Default} />

<Canvas of={UiSectionStories.TitleOnly} />

## Custom title

The `#title` slot replaces the icon and title; it gets both as slot props.

<Canvas of={UiSectionStories.CustomTitle} />

## Actions

Buttons go into `#actions`. Settings are a `UiSectionSettings`: a gear button opening its slot in a dialog.

<Canvas of={UiSectionStories.WithActions} />

## Collapsible

`collapsible` adds a button that folds the content. Bind `v-model:collapsed` to control it, the section keeps the
state itself otherwise.
